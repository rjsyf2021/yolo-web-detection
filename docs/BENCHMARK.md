# 基准测速与历史结果

[返回使用说明](../README.md)

本页保留项目此前记录的测速结果，本次文档整理没有重新测速。数据只描述所列条件，不代表当前每次提交或其他设备的性能。


```bash
python benchmark_fps.py --list
python benchmark_fps.py --image /path/to/sample.jpg --variants s m --render server
python benchmark_fps.py --image /path/to/sample.jpg --source-sizes original --render none
```

默认对比四种源画幅：1280×720、1920×1080、960×720、1440×1080，所有型号的网络输入均为 640×640。`server` 模式包含原分辨率画框，`none` 模式只测预测与坐标后处理。计时不含图片读取、源画幅生成、视频编解码或网络，不代表实时视频端到端 FPS。未提供本地默认图片时使用合成画面，不联网下载；合成图的检测数量与画框开销不代表真实素材。显存峰值仅统计 PyTorch 分配器，不覆盖全部 TensorRT/CUDA 分配。
